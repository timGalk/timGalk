## 🚀 Things I've built

### 💊 [RenalSafe](https://github.com/timGalk/renalsafe)

My academic project for **renal dose adjustment**: deterministic decisions, source-linked evidence, pharmacist rule review, and reproducible assessment history.

Built with **Go, React, PostgreSQL + pgvector, and Docker**. Academic prototype using synthetic patients; clinical validation is pending.

### 🐝 [BeeARD · Scientific discovery agents](https://github.com/Karo555/SolvroML/tree/main/hackathon/solvro)

A **Solvro team hackathon project** combining knowledge graphs, biomedical research retrieval, and LLM agents for hypothesis generation.

My part: **Europe PMC API integration and tools for bioRxiv and Ensembl**, connecting the workflow to scientific literature and biological data.

### 🧬 Bioinformatics corner

- **[NWAlgo](https://github.com/timGalk/NWAlgo)** — interactive Needleman–Wunsch sequence alignment, animated matrix visualization, and PDF / PNG reports. Built with **Kotlin & Compose Desktop**.
- **[UPGMA](https://github.com/timGalk/upgma)** — phylogenetic trees from sequences or distance matrices, with visualization and Newick / image export. Built with **Python, Biopython, NumPy & Matplotlib**.
